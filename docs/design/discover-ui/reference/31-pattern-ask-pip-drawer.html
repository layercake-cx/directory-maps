Why do searches for “chartered” find nothing?

Keyword search looks at entry names, descriptions and AI summaries. “Awards chartered status” is stored as a filter, so the word itself isn't searched.

You could include filter labels in keyword matching, or add a “Chartered” quick filter above results.
