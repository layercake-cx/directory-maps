Drag to reorder

One way to change order anywhere in the admin: grab the handle and pull the row up or down. Works with a mouse, a finger and the keyboard, saves on drop, and can be undone.

Saving

Standalone lists (Categories, filter fields, map groups, pages): save on drop, optimistically. Toast "Order saved" with Undo for 6s. If the save fails, the list snaps back and a danger Callout says "Couldn't save the new order. It's been put back." No Save button, no SaveBar. Lists inside a form with a SaveBar (prominent links, product tiles, media, team members, evidence, entry page sections): reordering marks the form dirty like any other edit. No toast. Order changes count as unpublished changes for directories, like every other edit.

Variants

Default: 64px rows in a bordered list, as above. Compact: 48px rows for repeatable items inside editor forms; the item's own fields sit in the row or expand under it. Nested (Pages only): dragging right of the drop line by 32px indents the slot one level ("Nest under About"); one level max, as today. Keyboard: → / ← to nest and un-nest while lifted. Reduced motion: no tilt, scale or slide; rows jump to their new place.
