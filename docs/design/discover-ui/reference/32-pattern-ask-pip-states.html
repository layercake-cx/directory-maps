Ask Pip: the assistant drawer

A side drawer that slides over the right of any admin page. It knows which page you're on, answers questions, points to settings and suggests changes you approve. AIButton stays for single in-place jobs ("Draft with AI"); Pip is for help and conversation.

Ways in

Top bar, every pageBetween search and help. Platform context: teal outline on ink. Keyboard: ⌘J / Ctrl+J toggles.

Small screensBelow 768px the drawer becomes a full-screen sheet under the top bar, with a close button and the same parts. Between 768 and 1280px it overlays with a scrim; above 1280px the scrim drops to 10% so the page stays readable for side-by-side work.
Layout440px wide (min 360, max 40vw), full height below the 52px top bar, slides in from the right over the panel and page (220ms ease-out; 160ms out). Scrim rgba(20,25,28,.18). Sits above SaveBar and toasts in z-order; the TaskIndicator stays visible.
BehaviourOpens with page context (workspace, directory, page, selected record). Conversation persists per workspace for the session; New conversation clears it. Esc, close button or scrim click closes and returns focus to the trigger. Pip never publishes, deletes or sends email; suggested changes need an explicit Apply.
Accessibilityrole=dialog, aria-modal, labelled by "Pip". Focus moves to the composer. New replies announced via a polite live region. Thinking state has a Stop button. Works without the avatar: every state has a text heading.
