Behaviour rules

SavingSettings and record editors (Templates 2–3): explicit save with SaveBar and leave-page guard. Single on/off SettingRows on overview pages: save instantly with a toast. Never mix the two on one page.
PublishingSaving never changes the live site. Saved edits become "Unpublished changes" until Publish. Every page that edits directory content links to Publishing from its saved state.
PermissionsView-only users don't see manage-only pages (as navConfig does today). Inside a page, actions they can't take are hidden; if hiding would confuse, show disabled with the reason.
LoadingSkeletons for first load, button label change for actions, Publishing… chip for long jobs. Spinners alone are not allowed.
Destructive actionsArchive over delete. Delete needs ConfirmDialog naming the count; bulk deletes over 10 ask to type the number.
AIOne AIButton per section; output is a draft with a provenance note; drafts count as unpublished changes. AI never publishes or sends anything by itself.
